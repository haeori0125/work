# 팀 투두리스트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 멤버가 이름+비밀번호로 로그인해 오늘/주간/지난 업무를 함께 체크하고, 출퇴근·메모를 기록하며, 관리자가 업무(반복 포함)와 멤버·출퇴근을 관리하는 Next.js 사이트를 Vercel에 배포한다.

**Architecture:** Next.js App Router 한 앱. 모든 업무 규칙은 `src/lib/*.ts`의 순수 함수/DB 함수(첫 인자 `db`)에 두고 vitest + PGlite(메모리 Postgres)로 테스트한다. 페이지는 서버 컴포넌트 + 서버 액션으로 lib 함수를 호출만 한다. 운영 DB는 Neon Postgres(`DATABASE_URL`), 없으면 로컬 PGlite 파일 DB.

**Tech Stack:** Next.js 16.4.6, React(Next가 요구하는 버전), TypeScript, drizzle-orm 0.45.4 / drizzle-kit 0.31.11, postgres(postgres-js), @electric-sql/pglite 0.5.17, bcryptjs 3.0.3, vitest 5.1.1, Playwright(사전 설치본).

**Spec:** `docs/superpowers/specs/2026-11-23-team-todo-design.md`

## Global Constraints

- 시간대는 Asia/Seoul 고정. "오늘", "자정", "이번 주"는 모두 KST 기준. 한 주는 월요일~일요일.
- 날짜는 문자열 `YYYY-MM-DD`(KST 달력 날짜), 시각은 `timestamptz`/`Date`.
- 화면 문구: "멤버 / 관리자" (로그인 탭 "멤버 / 관리자", 관리 화면 "멤버 관리"). UI는 한국어.
- 업무 상태 값 `todo | doing | done`, 화면 표기 "미체크 / 진행 중 / 완료".
- 공용 화면 명칭: "오늘 업무", "지난 업무", "이번 주 업무", "위클리", "오늘의 공용 메모", "내 기록", "개인 메모".
- 휴대폰 폭(360px)에서 가로 스크롤 없이 사용 가능.
- 커밋은 기본 브랜치 `claude/dreamy-brown-aq8sjn`에 직접, 태스크마다 커밋·푸시.
- 비밀번호는 bcrypt 해시로만 저장. 세션 토큰은 SHA-256 해시로만 저장, 쿠키는 httpOnly·SameSite=Lax·(운영) Secure.
- 비상업 모임용, Vercel Hobby + Neon 무료.

### Task 3: 반복 판정

**Files:** Create `src/lib/recurrence.ts`, Test `tests/lib/recurrence.test.ts`

**Interfaces:**
- Consumes: `kstWeekday`, `weekStartOf` (Task 2)
- Produces:
  - `type Kind = 'dated' | 'weekly'`; `type Repeat = 'none'|'daily'|'weekdays'|'weekly_days'|'weekly'`
  - `type RecurrenceSpec = { kind: Kind; repeat: Repeat; weekdays: number[]; startDate: string; endDate: string | null }`
  - `occursOn(spec, date: string): boolean` — dated 전용
  - `occursInWeek(spec, weekStart: string): boolean` — weekly 전용
  - `validateRecurrence(spec): string | null` — 오류 문구 또는 null

규칙: dated+none → date == startDate. daily → 범위 안 모든 날. weekdays → 범위 안 월~금. weekly_days → 범위 안 weekdays에 포함된 요일. weekly+none → weekStart == weekStartOf(startDate). weekly+weekly → weekStart ≥ weekStartOf(startDate) 이고 endDate 없거나 weekStart ≤ weekStartOf(endDate). 범위 = startDate ≤ date ≤ endDate(있으면).
검증: dated는 repeat ∈ {none,daily,weekdays,weekly_days}, weekly는 {none,weekly}; weekly_days인데 weekdays 비면 `"반복 요일을 하나 이상 선택하세요"`; endDate < startDate면 `"종료일이 시작일보다 빠릅니다"`.

- [ ] **Step 1: 실패하는 테스트** — 위 규칙 각각 1개 이상. 반드시 포함: daily 시작 `2026-11-25`이면 `occursOn(…,'2026-11-24') === false`; 종료 `2026-11-27`이면 `'2026-11-28'` false; weekdays는 `'2026-11-28'`(토) false; weekly_days `[0,2]`는 `'2026-11-25'`(수) true, `'2026-11-24'`(화) false; weekly_days `[]` 검증 메시지 일치.
- [ ] **Step 2:** FAIL → **Step 3:** 구현 → **Step 4:** PASS
- [ ] **Step 5:** 커밋·푸시 `feat: add recurrence rules`
